# Влияние отвлекающих факторов на успеваемость

**Автор: Даниил Пикулев**

Переделка исследования «Влияние отвлекающих факторов на успеваемость» (ШАГ 0–6), v2.
Пилотная **описательная** модель: времяпрепровождение предсказывает средний балл (GPA).

> **Терминология:** `Средний_Балл` — **зависимая** переменная (целевая, y);
> остальные — **независимые** (факторные, X).

## Ключевая находка

Пять переменных времени суммируются **ровно в 24.0 в 100% строк** (mean=min=max=24.000000) →
данные **композиционные** (бюджет 24 ч), матрица плана **сингулярна** (cond ~3e16).

Корректная спецификация: одна временная переменная исключается как референсная (`Часы_Сна`),
cond падает до 154. Коэффициенты интерпретируются как эффект **перераспределения 1 часа
ОТ сна К данной активности** при фиксированных остальных.

Дополнительно: forensic-признаки синтетики — все 5 часовых колонок на 100% кратны 0.1,
`std(суммы)` = 1.6e-15. Перенос результатов на живых студентов запрещён без внешней валидации.

## Датасет

Kaggle `steve1215rogg/student-lifestyle-dataset` (оригинал `lifestyle_dataset.xls`), n=2000, 8 колонок.
Файл — `student_lifestyle_dataset.csv`.

## Результаты (кратко)

- **R² на тесте ~55%** у линейной модели; ~45% дисперсии балла — вне модели.
  Линейная модель не хуже RidgeCV и RandomForest (даже после честного тюнинга).
- **Единственный значимый фактор при контроле остальных — `Часы_Учебы`:**
  +0.156 балла за +1 ч/день (перераспределённый от сна), 95% CI [0.140, 0.172], p≈5e-82.
- **Стресс после контроля учёбы НЕ значим** (p=0.811). Парная r=0.55 — это confounding:
  r(учёба, стресс)=0.74, а частная корреляция r(балл, стресс | учёба)=0.017.
- Остальные активности не значимы (все p>0.23).
- **Критерий успеха P(|ошибка| ≤ 0.15) ≥ 80% не пройден ни одной моделью** (лучшая — линейная, 52.0%).
  Решение `SHIP` заблокировано: критерий провален + данные синтетические.

## Вердикт по гипотезе: ЧАСТИЧНО ПОДТВЕРЖДЕНА

Описательная часть подтверждена (времяпрепровождение предсказывает балл), но причинная
интерпретация запрещена: один наблюдательный датасет, самоотбор, confounding (учёба↔стресс),
композиционность времени. Для управленческих решений нужны внешняя валидация и причинный дизайн
(A/B или лонгитюд на реальных данных).

## Запуск

Положите CSV рядом с `analysis.py` как `student_lifestyle_dataset.csv` либо задайте путь через
переменную окружения `STUDENT_LIFESTYLE_CSV`:

```bash
python3 analysis.py
```

Сплит 80/20 (`random_state=42`) + 5-fold CV (`random_state=42`). Для сопоставимости с исходником
проверен и `random_state=20`. Артефакты сохраняются в `output/`.

## Ограничения

Корреляция ≠ причинность; самоотчётные часы; один датасет; синтетичность замыкания на 24 ч;
узкая GPA-шкала (диапазон 1.76). Любой вывод без числа (эффект + CI + p) считается неготовым —
все числа приведены в `ОТЧЁТ_АНАЛИЗ.md`.
